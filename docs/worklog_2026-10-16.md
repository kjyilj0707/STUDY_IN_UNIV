## 저장 구조 (오늘 추가)

```
Supabase Storage  lectures 버킷 (비공개)
└── {user_id}/
    ├── {lecture_id}.pdf            ← 강의 PDF (기존)
    ├── {lecture_id}.memos.json     ← 필기 {"칸 번호": "글"}
    ├── {lecture_id}.edited.json    ← 편집본 {"html": …} (수식은 data-tex, 필기 칸은 이름표만)
    └── avatar.jpg                  ← 프로필 사진
Supabase DB  profiles 표에 display_name·school·department·grade·age·avatar_at·updated_at 추가
```

- 노트를 열 때: 편집본이 있으면 편집본, 없으면 원본 마크다운(DB `lectures.note`)을 그린다.
- 강의·과목을 지우면 필기·편집본 파일도 함께 지운다.
